How the slot behaves

  • YouTube, Vimeo and Drive links are normalised to their embed URL.
  • Direct .mp4 / .webm / .ogg links render a native video player.
  • An empty slot is a clean attach state, not a broken iframe.
  • Iframes are sandboxed and use a strict referrer policy.
  • The link is stored on this device only; clearing the browser clears it.

#LearnerPointsModulesCasesSaved
Why there is no real cohort table. The product deliberately keeps learner state on the learner's device. A faculty account cannot read another browser's localStorage, and there is no backend to aggregate it. Phase-2 could add an opt-in class code, but that is out of scope for P7.

Faculty can

  • Attach, replace or clear a video link per module on this device.
  • Preview the exact player the learner will see.
  • Copy a lesson link for a class handout or LMS.
  • Run the lab benches, investigations and case deck in class.
  • Reset the demo state on this device.

Faculty cannot

  • See a learner's scores, name or progress from another device.
  • Create accounts, enrol learners or run a cloud cohort.
  • Edit the statutory text or the 12 case holdings from this view.
  • Publish a video to every device — the link is local by design.
  • Bypass the sandbox or inject scripts into the learner page.
Owner boundary. Legal copy changes belong to the content owner (P2/P3); P7 owns the video slot, cases, progress and gamification surfaces.
